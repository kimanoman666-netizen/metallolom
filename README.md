# МЕТАЛЛОЛОМ

Шутер от первого лица на Godot 4 (физика Jolt) в духе Arc Raiders. Главное в игре — разбирать роботов на части.

Роботы смоделированы в Blender, каждая деталь у них отдельная. **Латунные суставы, глаза и роторы ломаются с одного попадания.** Остальные части можно отстрелить, если нанести им достаточно урона.

## Скачать

**[Последняя сборка → METALLOLOM.exe](../../releases/latest/download/METALLOLOM.exe)**

Это один файл, установка не нужна. Если Windows покажет «Система Windows защитила ваш компьютер», нажми **Подробнее → Выполнить в любом случае**.

## Роботы

| Робот | Что делает | Как разобрать |
|---|---|---|
| **Шершень** | дрон с двумя роторами, стреляет очередями | выбей глаз на стойке, и он ослепнет; без пушки идёт на таран; потеряв ротор, падает |
| **Краб** | броневая чаша на 4 ногах, таранит и стреляет из миномёта (красный круг — место падения снаряда) | латунные суставы ног; синий глаз получает тройной урон |
| **Прыгун** | огромный паук на 4 ногах, прыгает на тебя и бьёт ударной волной | колени ломаются с одного выстрела; без двух ног падает и ползёт; без глаза слепнет |
| **Ракетчик** | дрон на 4 роторах, наводит красный луч и даёт залп ракет | роторы ломаются с одного выстрела; без двух падает и взрывается |

## Оружие

1. Рычажная винтовка: мощная и точная, лучше всего для слабых точек.
2. Дробовик.
3. Миниган: стволам нужно раскрутиться.
4. Плазменный бластер: перегревается.
5. Лазерный резак.
6. Барабанный гранатомёт.
7. Ракетомёт.

## Управление

| Клавиша | Действие |
|---|---|
| WASD, Shift, Пробел | движение, бег, прыжок (в воздухе — второй прыжок) |
| ЛКМ / ПКМ | огонь / прицел |
| R | перезарядка |
| 1–7, колесо | выбор оружия |
| F (держать и отпустить) | суперудар кулаком |
| Q в воздухе | удар о землю |
| Esc | пауза и настройки |

## Как устроено

- `tools/blender/` — скрипты, которые строят модели роботов и оружия в Blender (`pip install bpy`):
  `python tools/blender/robots.py models` и `python tools/blender/weapons.py models/weapons`.
- `scripts/robot.gd` — роботы: IK-ноги, полёт на роторах, слабые точки, отрыв деталей.
- Каждый пуш в `main` запускает GitHub Actions. Сборка проверяет проект, прогоняет автотест (бот сам играет 37 секунд), собирает `METALLOLOM.exe` и выкладывает его в Releases.
