# МЕТАЛЛОЛОМ

Шутер от первого лица на Godot 4 (физика Jolt). Роботы собраны из отдельных частей, и каждую можно отстрелить: голову, руки, кисти, бёдра, голени. Оторванная часть становится физическим обломком, а робот теряет то, за что она отвечала:

- без головы стреляет почти вслепую;
- без руки с оружием бросается врукопашную;
- без ноги ползёт;
- без рук и ног взрывается сам.

## Скачать

**[Последняя сборка → METALLOLOM.exe](../../releases/latest/download/METALLOLOM.exe)**

Это один файл, установка не нужна. Если Windows покажет «Система Windows защитила ваш компьютер», нажми **Подробнее → Выполнить в любом случае**: у exe просто нет платной цифровой подписи.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Shift | бег |
| Пробел | прыжок (в воздухе — второй прыжок) |
| ЛКМ | огонь |
| 1 / 2 / 3, колесо | бластер / лазерный резак / ракетомёт |
| F или ПКМ (держать и отпустить) | суперудар: рывок кулаком, разносит роботов и стены |
| Q в воздухе | удар о землю: ударная волна |
| Esc | пауза и настройки |

## Что внутри

- 3 вида роботов: Скаут, Солдат, Громила. Каждый собран из 11 частей с отдельным здоровьем.
- Разрушаемые кирпичные стены: блоки, которые потеряли опору, обрушиваются.
- Ящики разлетаются на доски, бочки взрываются цепочкой.
- Волны роботов, высадка с неба, комбо и рекорд.
- Все модели, текстуры и звуки процедурные, генерируются кодом.

## Сборка

Каждый пуш в `main` запускает GitHub Actions. Он проверяет проект, прогоняет автотест (бот сам играет 37 секунд), собирает `METALLOLOM.exe` и выкладывает его в Releases.

Локально: открыть папку в Godot 4.6.1 и нажать F5.
